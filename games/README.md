# Static HTML5 games

این فایل‌ها frontend بازی هستند و باید روی HTTPS static hosting منتشر شوند.

- `air-raider/`
- `backgammon/`
- `voice-wheel/`

Backend Serverless این HTMLها را سرو نمی‌کند. بعد از انتشار، URLهای واقعی را در `lib/games.js` قرار بده.

Voice Wheel فعلی یک frontend مستقل است و به roster واقعی live voice chat متصل نیست.
